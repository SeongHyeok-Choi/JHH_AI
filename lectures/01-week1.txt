## 이번 주 목표

- 8주 동안 무엇을, 어떻게 배우는지 알기
- Claude와 Gemini 중 하나를 골라 설치하고 첫 대화 해 보기

## 1. 이 과정은 이렇게 진행돼요

### 무엇을 하는 과정인가요

AI 도구를 내 일에 직접 써 보는 과정이에요. 듣기만 하는 강의가 아니라, 매주 내용을 읽고 AI로 직접 따라 해 보는 방식이에요. 제출할 과제는 없어요.

| 항목 | 내용 |
|---|---|
| 기간 | 8주, 주 1회 |
| 소요 시간 | 읽기 20~30분 + 따라 하기 30분 |
| 쓰는 도구 | Claude (Anthropic) 또는 Gemini (Google) 중 하나 |
| 학습 자료 | 이 페이지 본문 + 참고 동영상 |

### 8주 흐름

주제는 상황에 따라 바뀔 수 있어요.

| 단계 | 주차 | 주제 |
|---|---|---|
| AI와의 만남 | 1주차 | 과정 안내와 AI 도구 설치 |
| AI와 친해지기 | 2주차 | 메일과 보고서 초안 만들기 |
| | 3주차 | 엑셀·데이터 반복 작업 줄이기 + 내 문서로 일 시키기 |
| | 4주차 | 회의 내용을 문서로 |
| | 5주차 | 자료 찾기와 검증: 인터넷 수집 → 검증 → 엑셀 리포트 → 반복 |
| AI와 놀아보기 | 6주차 | AI로 만들어 보기 (웹게임·음악·영상) |
| | 7주차 | 내 일 자동화 사례 만들기 |
| | 8주차 | 정리와 다음 단계 |

### 난이도는 어느 정도인가요

AI 도구를 거의 써 본 적 없는 사람을 기준으로 시작해요. 이미 써 본 적이 있다면 초반은 쉬울 수 있어요. 아는 내용은 넘기고 따라 하기만 해도 괜찮아요.

과정은 세 단계로 가요.

| 단계 | 주차 | 무엇을 하나 |
|---|---|---|
| AI와의 만남 | 1주차 | 도구를 손에 넣고, AI에 넣으면 안 되는 것부터 알아요 |
| AI와 친해지기 | 2~5주차 | 자주 하는 일 하나를 AI에게 맡겨 보고, 그 답을 의심하는 법까지 익혀요 |
| AI와 놀아보기 | 6~8주차 | AI를 가지고 놀아 봐요 |

여기서 「논다」는 여가가 아니라 경지를 말해요. 악기를 가지고 논다고 할 때와 같은 뜻이에요. 8주차는 끝이 아니라 시작이에요. 이 과정에서는 노는 법을 맛보고, 제대로 가지고 노는 건 과정이 끝난 뒤 각자의 일에서 이어져요.

1주차는 준비 단계라 분량이 가벼워요. 실제 활용은 2주차부터, 내 PC의 문서를 다루는 건 3주차부터 시작해요.

## 2. Claude와 Gemini, 하나만 고르세요

이 과정은 **Claude와 Gemini 중 하나만** 써도 충분해요. 두 개를 다 설치하거나 매번 비교할 필요는 없어요. 손에 익은 도구 하나를 꾸준히 쓰는 쪽이 더 빨리 늘어요.

| | Claude | Gemini |
|---|---|---|
| 만든 곳 | Anthropic | Google |
| 로그인 | 이메일 또는 Google 계정 | Google 계정 |
| 데스크톱 앱 | Windows · Mac | Windows · Mac |
| 이런 분께 | 내 PC의 파일과 폴더를 AI에게 직접 맡기고 싶은 분 | Gmail·Google 드라이브를 이미 많이 쓰는 분 |

어느 쪽을 골라도 이 과정을 따라오는 데 문제는 없어요. 고르기 어렵다면 이렇게 정하세요.

- Google 계정을 이미 쓰고 있고 빨리 시작하고 싶다 → **Gemini**
- 앞으로 내 PC의 문서와 폴더를 AI로 많이 다룰 것 같다 → **Claude**

나중에 바꾸고 싶으면 그때 다른 쪽을 설치해도 돼요.

## 3. 이 강의실에서는 이렇게 따라 하면 돼요

| 순서 | 할 일 |
|---|---|
| 1 | 새 주차가 올라오면 왼쪽 목록에 추가돼요 |
| 2 | 본문과 참고 동영상으로 읽어요 (20~30분) |
| 3 | 본문의 「따라 해 보기」를 고른 도구로 직접 해 봐요 (30분) |
| 4 | 다 했으면 맨 아래 **완료** 버튼을 눌러 표시해요 |

제출, 채점, 마감은 없어요. 자기 속도에 맞춰 하면 돼요. 막히는 곳이 있으면 편하게 물어보세요.

## 4. 고른 도구 설치하기

### 어떤 방식으로 쓸까요

| 방식 | 무엇인가 | 누가 주로 쓰나 |
|---|---|---|
| 웹 브라우저 | 사이트에 접속해서 대화. 설치 필요 없음 | 처음 시작할 때, 아무 PC에서나 |
| 데스크톱 앱 | 설치형. 단축키로 바로 열 수 있음 | 매일 쓰는 사람 |

이 과정은 **데스크톱 앱**을 기준으로 해요. 매일 쓰려면 단축키로 바로 여는 게 훨씬 편해요. 회사 PC라 설치 권한이 막혀 있다면 개인 PC에 설치하거나, 웹 브라우저로 써도 괜찮아요.

- Claude 웹: claude.ai
- Gemini 웹: gemini.google.com

### 설치 순서 (어느 도구든 같아요)

1. 공식 사이트에서 데스크톱 앱을 내려받아요. 검색 결과의 광고 링크 말고, 공식 주소가 맞는지 꼭 확인하세요.
   - Claude: [claude.ai/download](https://claude.ai/download)
   - Gemini (Windows): [gemini.google/desktop](https://gemini.google/desktop/)
   - Gemini (Mac, macOS 15 이상): [gemini.google/mac](https://gemini.google/mac)
2. 설치한 다음 내 계정으로 로그인해요. Gemini는 Google 계정으로 로그인해요.
3. 아무 질문이나 하나 넣어 보고 잘 되는지 확인해요.

> **AI에 넣으면 안 되는 것**
> 이 과정의 실습은 개인 계정과 일과 상관없는 자료로 해도 충분해요. 다만 회사 일에 쓸 때는 회사가 허용한 도구와 회사 계정만 쓰세요. 개인 계정으로 가입한 서비스에는 회사 자료, 고객 정보, 개인정보를 넣지 마세요. 개인 계정에는 회사의 데이터 보호 설정이 걸려 있지 않아요.

### Claude를 골랐다면

Claude 안에는 도구가 셋 있어요. **채팅 · Cowork · Code** 중 하나를 골라 써요. 고르는 기준은 하나예요. 답이 필요한가, 파일이 필요한가.

| | 채팅 (Chat) | Cowork | Code |
|---|---|---|---|
| 무엇이 필요할 때 | 읽고 판단한 답 | 손에 쥘 파일 | 돌아가는 프로그램 |
| 하는 일 | 파일을 붙여 요약·분석하고, 글을 쓰고 고쳐요 | 지정한 폴더의 파일을 직접 열어 고치고, 문서를 만들어 저장해요 | 필요한 작은 도구를 만들어요 |
| 내 PC 파일 | 건드리지 않아요 | 직접 읽고 써요 | 직접 읽고 써요 |

1주차에는 **채팅만** 써 봐도 충분해요. Cowork는 3주차에 내 문서를 다루기 시작하면 자연스럽게 쓰게 되고, Code는 개발·데이터 일이 아니면 지금은 필요 없어요.

앱을 열면 왼쪽 메뉴가 **채팅 및 Cowork**와 **Claude Code** 둘로 나뉘어 있어요.

- Claude Code가 선택돼 있으면 먼저 **채팅 및 Cowork**를 눌러요.
- 그 안에서 **채팅**이 눌려 있으면 채팅이, **Cowork**를 누르면 Cowork가 동작해요.
- Cowork를 쓰려면 작업할 폴더를 하나 붙여야 해요. **폴더 추가**로 폴더를 고르고 옆의 별표를 누르면 기본 폴더가 돼요. 1주차에는 안 해도 되고, 3주차에 해 두면 돼요.
- 오른쪽 위에 「클라우드에서 / 컴퓨터에서」가 보이면 **컴퓨터에서**로 두세요. 안 보이면 건드리지 않아도 돼요.

> **Windows에서 Cowork 버튼이 안 눌릴 때**
> 대개 PC의 가상화 기능이 꺼져 있어서예요. 화면에 뜬 안내 문구를 그대로 복사해서 채팅에 붙여 넣고 「이 이유로 Cowork가 안 되는데 고치는 방법을 알려줘」라고 물어보세요. 내 PC에 맞는 순서를 알려 줘요. 보통 설정을 바꾸고 한 번 재부팅하면 돼요. 1주차에는 지장 없어요.

### Gemini를 골랐다면

- Google 계정으로 로그인하면 바로 쓸 수 있어요.
- **Alt + Space**(Windows) 또는 **Option + Space**(Mac)를 누르면 지금 보던 화면 위로 Gemini가 바로 떠요.
- 파일은 대화창에 끌어다 놓거나 첨부해서 요약·분석을 시킬 수 있어요.
- Gmail, Google 드라이브와 연결해서 쓰는 기능도 있어요. 1주차에는 대화만 해 봐도 충분해요.

### 참고 동영상 (Claude를 고른 경우)

도구 화면과 기능은 자주 바뀌어요. 동영상은 설치가 어떻게 흘러가는지 보는 용도예요. 실제 화면이 다르면 공식 안내를 따르세요. 유튜브에서 제목으로 검색하면 나와요.

**(Claude) 데스크톱 앱 설치: 웹에서는 폴더를 못 읽습니다** · 7분 30초 · 미드저니 코리아 조남경

- 볼 구간: **0분 46초 ~ 4분** (약 3분)
- 0분 46초 다운로드·설치 → 2분 15초 채팅과 Cowork 바꾸기 → 2분 32초 Windows에서 버튼이 안 눌릴 때 → 4분 작업 폴더 만들고 기본값으로 고정

Gemini는 설치가 단순해서 위 설치 순서만 따라 해도 충분해요.

## 따라 해 보기

고른 도구 **하나만** 설치하고 로그인까지 되면 끝이에요.

1. Claude 또는 Gemini 중 하나를 골라 데스크톱 앱을 설치해요.
2. 로그인해요. 화면 한쪽에 **내 계정 이름이나 프로필 사진이 보이면** 로그인된 거예요.
3. 아래 질문을 그대로 넣어 보세요.

```text
나는 AI 도구를 처음 써 봐. 앞으로 8주 동안 AI로 메일 쓰기, 엑셀 정리, 회의록 만들기를 배울 거야. 시작하기 전에 알아 두면 좋은 점 3가지만 짧게 알려줘.
```

4. 답을 읽어 보고, 이어서 궁금한 걸 하나 더 물어보세요. 예를 들면 「두 번째 내용을 예시로 더 쉽게 설명해줘」처럼요. 이렇게 이어서 묻는 게 AI와 대화하는 기본이에요.

설치나 로그인이 막히면 혼자 붙잡고 있지 말고, 어디서 어떤 오류가 났는지 캡처해서 물어보세요.
