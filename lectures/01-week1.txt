## 1. 이 과정은 이렇게 진행돼요

### 무엇을 하는 과정인가요

AI 도구를 내 일에 직접 써 보는 과정이에요. 듣기만 하는 강의가 아니라, 매주 내용을 읽고 AI로 직접 따라 해 보는 방식이에요. 제출할 과제는 없어요.

| 항목 | 내용 |
|---|---|
| 기간 | 8주, 주 1회 |
| 소요 시간 | 읽기 20~30분 + 따라 하기 30분 |
| 쓰는 도구 | Claude (Anthropic), ChatGPT (OpenAI) |
| 학습 자료 | 이 페이지 본문 + 참고 동영상 |

### 8주 흐름

주제는 상황에 따라 바뀔 수 있어요.

| 단계 | 주차 | 주제 |
|---|---|---|
| AI와의 만남 | 1주차 | 과정 안내와 AI 도구 설치 |
| AI와 친해지기 | 2주차 | 메일과 보고서 초안 만들기 |
| | 3주차 | 엑셀·데이터 반복 작업 줄이기 + 내 문서로 일 시키기 |

| | 8주차 | 정리와 다음 단계 |

### 난이도는 어느 정도인가요

AI 도구를 거의 써 본 적 없는 사람을 기준으로 시작해요. 이미 써 본 적이 있다면 초반은 쉬울 수 있어요. 아는 내용은 넘기고 따라 하기만 해도 괜찮아요.

과정은 세 단계로 가요.

| 단계 | 주차 | 무엇을 하나 |
|---|---|---|
| AI와의 만남 | 1주차 | 도구를 손에 넣고, AI에 넣으면 안 되는 것부터 알아요 |
| AI와 친해지기 | 2~5주차 | 자주 하는 일 하나를 AI에게 맡겨 보고, 그 답을 의심하는 법까지 익혀요 |
| AI와 놀아보기 | 6~8주차 | AI를 가지고 놀아 봐요 |

여기서 「논다」는 여가가 아니라 경지를 말해요. 악기를 가지고 논다고 할 때와 같은 뜻이에요. 8주차는 끝이 아니라 시작이에요. 이 과정에서는 노는 법을 맛보고, 제대로 가지고 노는 건 과정이 끝난 뒤 각자의 일에서 이어져요.

1주차는 준비 단계라 분량이 가벼워요. 실제 활용은 2주차부터, 내 PC의 문서를 폴더째 다루는 건 3주차부터 시작해요.

### 왜 두 도구를 같이 쓰나요

2주차부터는 같은 일을 Claude와 ChatGPT 양쪽에서 해 봐요. 마지막에 어느 쪽이 그 일에 더 잘 맞았는지 1~2줄만 메모해 두면 좋아요. 둘 다 쓰기 어렵다면 하나만 설치해도 괜찮아요.

한 도구만 쓰면 그 도구의 방식에만 익숙해져요. 같은 일을 양쪽에 넣어 보면 어떤 일에 어느 도구가 맞는지 감이 잡혀요. 그래서 1주차에 두 도구를 모두 설치해요.

## 3. Claude / ChatGPT 설치하기

### 어떤 방식으로 쓸까요

| 방식 | 무엇인가 | 누가 주로 쓰나 |
|---|---|---|
| 웹 브라우저 | 사이트에 접속해서 대화. 설치 필요 없음 | 처음 시작할 때, 아무 PC에서나 |
| 데스크톱 앱 | 설치형. 단축키로 바로 열고 파일 다루기 편함 | 매일 쓰는 사람 |

이 과정은 **데스크톱 앱**을 기준으로 해요.

앞으로 하는 일은 대부분 내 PC 폴더에 있는 문서를 다루는 일이에요. 보고서 초안, 회의록, 엑셀 자료 모두 파일로 주고받고, 결과물도 다시 파일로 남겨요. 데스크톱 앱이 이 흐름에 맞춰져 있어요. 회사 PC라 설치 권한이 막혀 있다면 개인 PC에 설치해도 괜찮아요.

### Claude 안에는 도구가 셋 있어요

설치하고 나면 Claude 안에서 **채팅 · Cowork · Code** 중 하나를 골라 써요. 고르는 기준은 하나예요. 답이 필요한가, 파일이 필요한가.

| | 채팅 (Chat) | Cowork | Code |
|---|---|---|---|
| 무엇이 필요할 때 | 읽고 판단한 답 | 손에 쥘 파일 | 돌아가는 프로그램 |
| 하는 일 | 파일을 붙여 요약·분석하고, 글을 쓰고 고쳐요 | 지정한 폴더의 파일을 직접 열어 고치고, 문서를 만들어 저장해요 | 필요한 작은 도구를 만들어요 |
| 내 PC 파일 | 건드리지 않아요 | 직접 읽고 써요 | 직접 읽고 써요 |
| 반복 | 한 번 | 매번 반복 | 한 번 만들어 예약 |
| 쓰는 방식 | 그 자리에서 시키고 받아요 | 폴더를 지정하고 결과물을 확인해요 | 한 번 만들고 예약해 둬요 |

1주차에는 **채팅만** 써 봐도 충분해요. Cowork는 실제 파일을 다루기 시작하면 자연스럽게 쓰게 되고, Code는 개발·데이터 일이 아니면 지금은 필요 없어요.

### 셋은 앱 어디에 있나요

데스크톱 앱을 열고 왼쪽 메뉴부터 보세요. 왼쪽이 둘로 나뉘어 있어요.

| 왼쪽 메뉴 | 여기서 쓰는 것 |
|---|---|
| 채팅 및 Cowork | 채팅과 Cowork 둘 다 여기 있어요 |
| Claude Code | Code. 개발·데이터 일이 아니면 지금은 안 들어가도 돼요 |

채팅과 Cowork는 같은 화면에서 버튼으로 바꿔요. 지금 선택된 쪽이 지금 쓰는 도구예요.

- 앱을 열었을 때 Claude Code가 선택돼 있으면, 먼저 **채팅 및 Cowork**를 눌러요.
- 그 안에서 **채팅**이 눌려 있으면 채팅이, **Cowork**를 누르면 Cowork가 동작해요.
- Cowork를 쓰려면 작업할 폴더를 하나 붙여야 해요. **폴더 추가**로 폴더를 고르고, 옆의 별표를 누르면 기본 폴더가 돼서 매번 고르지 않아도 돼요.
- 폴더는 아무 데나 새로 만들면 돼요 (예: 바탕화면에 「AI」 폴더). 1주차에는 안 해도 되고, 3주차에 해 두면 돼요.

> **Windows에서 Cowork 버튼이 안 눌릴 때**
> 대개 PC의 가상화 기능이 꺼져 있어서예요. 화면에 뜬 안내 문구를 그대로 복사해서 채팅에 붙여 넣고 「이 이유로 Cowork가 안 되는데 고치는 방법을 알려줘」라고 물어보세요. 내 PC에 맞는 순서를 알려 줘요. 보통 설정을 바꾸고 한 번 재부팅하면 돼요. 그래도 안 되면 물어보세요. 1주차에는 지장 없어요.

오른쪽 위에 「클라우드에서 / 컴퓨터에서」를 고르는 자리가 보이면 **컴퓨터에서**로 두세요. 이 메뉴가 안 보이면 이미 그렇게 되어 있는 거라 건드리지 않아도 돼요.

화면은 자주 바뀌어요. 버튼 이름이나 자리가 다르면 아래 참고 동영상 ①에서 실제 화면을 보세요. 2분 15초가 채팅과 Cowork를 바꾸는 장면, 2분 32초가 Windows 문제, 4분이 작업 폴더를 붙이는 장면이에요.
