## 이번 주 목표

- AI로 잘 만드는 원칙을 안다 — 작게 시작하고, AI가 먼저 묻게 하고, 증상으로 고친다
- 모션그래픽이 무엇이고 AI로 어떻게 만드는지 안다 — 코드로 만드는 영상
- AI로 영상을 만드는 방식과 대표 서비스, 쓸 때 조심할 점을 안다

## 지난주까지는

5주차에는 AI를 다른 서비스에 연결했어요. 이번 주에는 업무에서 잠시 벗어나 게임·영상을 끝까지 만들어 봐요. 여기서 익힌 **먼저 묻게 하기 · 증상으로 고치기 · 되돌리기**는 업무에도 그대로 써요. 5주차에 배운 커넥터는 힉스필드에서 한 번 더 써 볼 수 있어요(선택).

## 1. 웹게임을 잘 만드는 원칙

웹게임은 브라우저에서 바로 열리는 **HTML 파일 하나**로 만든 게임이에요. 설치할 것이 없고, 파일 하나만 주면 누구나 해 볼 수 있어요. AI는 몇 분 만에 게임을 만들어 주지만, 잘 만들려면 사람이 정할 것을 먼저 정해야 해요.

| 원칙 | 왜 | 예 |
|---|---|---|
| 규칙 하나로 작게 | 처음부터 큰 게임을 시키면 고칠 곳이 많아 끝나지 않아요. 하나가 돌아간 뒤에 늘려요 | 「떨어지는 것 피하기」 · 「과일 받기」 · 「두더지 맞히기」 중 하나 |
| 만들기 전에 먼저 묻게 | AI는 내가 정하지 않은 것을 묻지 않고 그럴듯하게 메워요. 질문을 받으면 빠뜨린 조건이 드러나요 | 「조작은 방향키인가요, 마우스인가요?」 · 「언제 끝나나요?」 |
| 파일 하나 · 바깥 주소 없이 | 다른 파일을 부르면 옮기는 순간 안 나와요. 바깥 주소(라이브러리·웹 폰트)를 부르면 인터넷이 막힌 곳이나 다른 사람 화면에서 깨져요 | 그림 파일 없이 도형·색으로 그리고, 소리·코드를 모두 HTML 안에 넣기 |
| 「클릭해서 시작」 | 브라우저는 사람이 한 번 누르기 전에는 소리를 막고, 키보드 입력도 게임에 가지 않아요 | 첫 화면에 「클릭해서 시작」을 두기 |
| 증상으로 고치기 | 「이상해」 대신 **무엇을 했더니 → 무엇이 나왔고 → 무엇이 나와야 하는지**를 말해요. 한 번에 하나씩 고쳐요 | 「주인공이 화면 밖으로 반쯤 나가. 화면 안에서만 움직이게 해줘」 |
| 되돌리기 | 고친 뒤 더 망가지면 고치기 전으로 돌려요 | 「방금 고친 것을 되돌려줘」 |
| 직접 해 보고 확인 | AI가 「지켰다」고 해도 실제로는 안 지킨 경우가 있어요 | 파일을 빈 폴더로 옮겨 열어 보기 |
| 소리까지 | 규칙 하나짜리 게임은 짧아서, 소리가 있어야 게임처럼 느껴져요. 소리도 바깥 파일 없이 코드로 만들 수 있어요 | 점수를 얻으면 「띵」, 부딪히면 「쿵」, 낮게 깔리는 배경음 |

> **모델은 기본으로 충분해요.** 메뉴에서 가장 크고 비싼 모델을 고르면 사용량을 많이 써요. 이번 게임은 기본 모델로 충분해요.

**참고 동영상:** 유튜브에서 「코딩 몰라도 AI로 게임 만들기」로 검색해 10분 안팎짜리 하나를 보세요. 단, 우리 실습에서는 **다른 회사의 캐릭터·그림을 따라 만들지 않아요.**

## 2. 모션그래픽 — AI로 코드로 만드는 영상

모션그래픽은 글자·도형·그림이 움직이며 내용을 전하는 영상이에요. 촬영 없이 만들 수 있어 회사 소개·제품 소개·사용법 안내에 많이 써요.

AI로 만들 때는 **Claude Code가 영상을 코드로 쓰고, 프로그램(Remotion, HyperFrames 등)이 그 코드를 MP4로 만들어요.** 그래서 3번의 생성형 영상과 성격이 달라요.

- **글자·숫자가 정확해요** — 내가 준 문장이 그대로 화면에 나와요
- **한 곳만 고치기 쉬워요** — 「12초의 제목만 2초 더」처럼 고친 곳 외에는 그대로예요
- **다시 만들어도 같아요** — 같은 코드는 늘 같은 영상이 돼요

잘 만드는 비결은 셋이에요.

| 비결 | 무엇 | 왜 |
|---|---|---|
| 레퍼런스 | 「이런 느낌으로」 — 마음에 드는 영상·웹사이트의 링크나 캡처 | 「멋지게」는 사람마다 달라요. 보여 주면 한 번에 통해요. 「네온 색은 쓰지 마」처럼 하지 말 것도 잘 통해요 |
| 자료 | 「무엇을 말할지」 — 홈페이지 주소, 공개용 소개 PDF, 매뉴얼 | 자료가 없으면 AI가 숫자와 사실을 지어내요 |
| 대본 · 장면표 | 「어떤 순서로」 — 장면마다 화면과 자막 | 장면표를 먼저 받아 승인하고 만들게 하면 고칠 곳이 크게 줄어요 |

**참고 동영상:** 유튜브에서 「Claude Code Remotion 모션그래픽」으로 검색해 보세요. 레퍼런스로는 **jasonzhu.ai**(Claude로 만든 모션그래픽 모음, 작품마다 보낸 말이 함께 있어요)와 **skillry.dev**(영상 종류별 만드는 법 모음)를 둘러보면 좋아요.

> **Gemini를 골랐다면:** 모션그래픽(MP4로 만들기)은 내 PC에서 프로그램을 돌려야 해서 Claude Code에서 해요. Gemini라면 본 실습은 3번 힉스필드 영상을 고르세요.

## 3. AI로 영상을 만드는 방식

요즘은 촬영 없이 글·그림·원래 영상을 주면 AI가 실제 같은 장면을 만들어 내요. 이것을 **생성형 영상**이라고 해요. 방식은 크게 네 가지예요.

| 방식 | 무엇을 주면 | 무엇이 나오나 | 서비스 예 |
|---|---|---|---|
| 글 · 그림 → 영상 | 장면을 글로 설명하거나, 그림 한 장 + 움직임 설명 | 몇 초짜리 실사·애니메이션 장면 | 대부분의 서비스 — Sora(OpenAI) · Veo(Google) · Kling · Runway · 힉스필드 |
| 움직임 옮기기 | 원래 영상 + 내 캐릭터 그림 | 원래 영상의 춤·동작을 내 캐릭터가 하는 영상 | 힉스필드 |
| AI 인물 · 인플루언서 | 사진이나 캐릭터 + 대본 | 같은 인물이 계속 나와 말하거나 움직이는 영상 | 힉스필드 · HeyGen |
| 코드로 만드는 영상 | 자료 + 대본 | 글자·도형이 움직이는 모션그래픽(2번) | Claude Code |

서비스 이름과 기능은 자주 바뀌어요. 지금 어떤 것이 되는지는 AI에게 물어보면 돼요. (Gemini 앱에도 Veo로 영상을 만드는 기능이 있지만, 요금제에 따라 횟수가 아주 적거나 없어요.)

생성형 영상과 모션그래픽은 잘하는 것이 달라요.

| | 생성형 영상 | 모션그래픽(코드) |
|---|---|---|
| 잘하는 것 | 실제 같은 사람·풍경·움직임 | 정확한 글자·숫자·도표 |
| 같은 말로 다시 만들면 | 매번 다르게 나와요 | 늘 같아요 |
| 한 곳만 고치기 | 어려워요 — 다시 만들어야 해요 | 쉬워요 |
| 화면 속 글자 | 자주 깨지거나 틀려요 | 준 그대로 나와요 |
| 비용 | 만들 때마다 크레딧을 써요. 무료는 몇 번뿐이에요 | 내 PC에서 만들어 따로 들지 않아요 |

### 힉스필드란

**힉스필드(Higgsfield)**는 여러 영상 모델을 한곳에서 쓰는 생성형 영상 서비스예요. 글·그림으로 장면을 만들거나, 그림을 움직이거나, 원래 영상의 움직임을 옮기는 등 위 표의 여러 방식을 한곳에서 할 수 있어요.

- **AI 인플루언서:** 여러 영상에 같은 인물이 나오게 하고 싶을 때, 사진 한 장이나 설명만으로 캐릭터를 만들어 두는 보조 기능이에요. 꼭 거쳐야 하는 단계는 아니에요.
- **유행 동작(챌린지):** 힉스필드가 골라 둔 예시 동작이에요. 캐릭터 그림을 넣고 동작 하나만 고르면 처음 써 보는 사람도 짧은 영상을 가볍게 만들 수 있어 이번 실습의 예로 써요. 원래 영상의 움직임과 카메라는 그대로 두고 사람만 바꾸는 「움직임 옮기기」예요.
- 유행 동작 대신 **동작을 글로 적어** 캐릭터 그림을 움직이게 할 수도 있어요(위 표의 「글 · 그림 → 영상」).
- 참고 글: [힉스필드로 내 캐릭터가 춤추는 영상을 만든 과정](https://aoworld.tistory.com/171) · [힉스필드 AI Influencer](https://higgsfield.ai/ai-influencer)

### 힉스필드 커넥터 (선택, Claude)

5주차처럼 Claude에 힉스필드를 연결하면, 대화에서 **남은 크레딧, 영상 한 개에 드는 크레딧, 어울리는 프리셋**을 물어볼 수 있어요.

- 커넥터는 필수가 아니에요. **무료 생성은 힉스필드 사이트에서만 되고 커넥터로는 안 돼요.** 무료 계정은 커넥터로 무언가를 만들 크레딧이 없으니, 커넥터로는 **상태만 확인**해요.
- 대화창에 붙인 그림·영상은 커넥터가 읽지 못해요. 실제로 만드는 일은 힉스필드 사이트에서 직접 해요.
- 커넥터는 크레딧을 얼마나 쓸지 스스로 멈추지 않아요. 「만들기 전에 비용을 알려 주고 기다려」라고 먼저 말해 둬요.
- Gemini는 목록에 없는 서비스를 직접 붙이는 기능이 아직 한국에서 안 되니(5주차 참고), 사이트 화면에서 크레딧을 보면 돼요.

### 생성형 영상을 쓸 때 조심할 것

- **얼굴** — 다른 사람(지인·연예인)의 얼굴로 만들지 않아요. 실제 사람처럼 보이는 가짜 영상(딥페이크)은 본인이 동의하지 않았으면 문제가 돼요
- **원래 영상 · 음악** — 남의 뮤직비디오·방송 영상·곡에는 저작권이 있어요. 내려받아 쓰고 다른 사람에게 보여 주면 문제가 될 수 있어요
- **AI로 만들었다고 밝히기** — 실제 같은 영상일수록 보는 사람이 진짜로 믿을 수 있어요
- **바깥 서비스에 올리는 것** — 사진·영상을 올리면 그 회사 서버에 남아요. 회사 자료·업무 사진은 올리지 않아요
- **비용과 약관** — 무료는 몇 번뿐이고, 만든 영상을 어디까지 쓸 수 있는지는 서비스 약관이 정해요

**참고 동영상:** 유튜브에서 「힉스필드 AI 인플루언서 무료」로 검색하면 무료 생성으로 캐릭터를 만들고 짧은 영상까지 이어 가는 과정을 볼 수 있어요.

## 따라 해 보기

먼저 몸풀기로 웹게임을 만들고, 본 실습은 모션그래픽·힉스필드 영상 중 하나를 골라요. **새 폴더를 하나 만들어** 거기서 해요. 제출할 건 없어요.

**보낼 말은 내가 써요.** 무엇을 어떻게 보내야 할지 모르겠으면 이렇게 보내고, AI의 질문에 답하면서 보낼 말을 함께 만들어요.

```text
이 일을 하려면 너에게 어떻게 말하면 될지 나에게 먼저 물어봐 줘.
```

완벽하게 만들려고 하지 않아요. 한 번 만들고 두세 번 고쳐 보면서 「이렇게 말하면 이렇게 바뀌는구나」 하는 느낌을 잡으면 돼요.

| 순서 | 무엇을 만드나 | 어디서 | 시간 | 결과 |
|---|---|---|---|---|
| 몸풀기 | 웹게임 — 규칙 하나 + 효과음·배경음, 화면은 코드로 | Claude 또는 Gemini | 25분 | HTML 파일 하나 |
| 본 실습 ① | 모션그래픽 — 30초 안팎, 주제 자유 | Claude Code | 60분 | MP4 |
| 본 실습 ② | 힉스필드 영상 — 내 캐릭터가 움직이는 짧은 영상 | 기획·검토는 Claude 또는 Gemini, 만들기는 힉스필드 사이트 | 60분 | MP4 |

### 몸풀기 — 웹게임

그림 파일은 따로 만들지 않아요. 게임 화면은 AI가 코드로(도형·색) 그려요.

**Claude라면** 새 폴더를 연결한 대화창에서, **Gemini라면** 입력창의 **캔버스**를 켜고 보내요. 아직 게임을 만들지 않아요.

```text
브라우저에서 돌아가는 간단한 게임을 HTML 로 만들고 싶어. 아직 만들지 말고, 무엇을 만들지 정하는 데 필요한 질문을 두 개만 먼저 해줘.
```

AI의 질문에 답해 만들 게임이 정해지면 보내요.

```text
정한 대로 게임을 HTML 파일 하나로 만들어줘.
다른 사람에게 파일만 보내도 새 창에서 해 볼 수 있게 하려고 해. 아래를 꼭 지켜줘.
- 그림 파일은 쓰지 마. 캐릭터와 배경은 도형과 색으로 코드에서 그려줘
- 소리 · 코드를 모두 HTML 안에 넣어서, 이 파일 하나만 옮겨도 그대로 돌아가게 해줘
- 외부 주소 · 외부 라이브러리 · 웹 폰트는 쓰지 마
- localStorage · alert · confirm · prompt 는 쓰지 마. 점수와 안내는 게임 화면 안에 글자로 보여줘
- 처음에는 「클릭해서 시작」 화면을 두고, 클릭한 뒤에 키보드 입력과 소리가 시작되게 해줘
- 창 크기에 맞춰 게임 화면이 늘고 줄게 해줘
- 효과음과 배경음을 바깥 파일 없이 코드로 만들어 넣어줘. 화면에 소리 끄기 · 켜기 버튼도 둬줘
다 만들면 위 조건을 하나씩 지켰는지 알려줘.
```

> **Gemini라면:** 캔버스 화면에서 바로 해 볼 수 있어요. 파일로 남기려면 코드 보기에서 전체 코드를 복사해 메모장에 붙이고 `game.html`로 저장하세요(파일 형식은 「모든 파일」, 인코딩은 UTF-8).

AI가 「지켰다」고 해도 **직접 확인**해요.

| 확인 | 어떻게 | 안 되면 증상으로 |
|---|---|---|
| 파일 하나로 도는가 | HTML 파일 하나만 빈 폴더로 옮겨 더블클릭 | 「파일을 옮겼더니 화면이 비어 있어. 다른 파일을 부르지 말고 HTML 안의 코드로만 그려줘」 |
| 바깥 주소가 없는가 | 메모장으로 열어 「src=」와 「&lt;link」를 찾고, 그 줄에 http 가 있는지 본다 | 「○○ 줄이 바깥 주소를 불러. 빼고 파일 안의 코드로 바꿔줘」 |
| 클릭해야 시작하는가 | 처음 열었을 때 「클릭해서 시작」이 보이고, 클릭 뒤에 키보드가 먹는가 | 「클릭했는데 방향키가 안 먹어」 |
| 창 크기에 맞는가 | 창을 줄였다 늘려 본다 | 「창을 줄이면 오른쪽이 잘려」 |
| 소리가 나는가 | 클릭해서 시작한 뒤 효과음·배경음이 들리고, 끄기 버튼이 되는가 | 「점수를 얻어도 소리가 안 나」 |
| 넣으면 안 되는 것이 없는가 | 사람 이름·업무 자료·회사 이야기가 들어 있지 않은가 | — 직접 지워요 |

### 본 실습 ① 모션그래픽 (Claude)

유튜브의 참고 영상을 먼저 보고, Claude Code에서 만들어요. 프로그램 설치가 들어가요. 설치나 명령 실행을 묻는 창은 3주차처럼 **내용을 읽고 그때마다 허용**해요. 어떻게 시작할지 모르겠으면 Claude Code에 「Remotion 으로 모션그래픽을 만들고 싶어. 내 PC에 무엇을 설치해야 하는지 먼저 알려주고, 설치는 하나씩 물어보면서 해줘」라고 보내세요.

주제는 자유예요. 정하기 어려우면 아래에서 골라요.

| 주제 예 | AI에게 줄 자료 | 레퍼런스 찾기 |
|---|---|---|
| 내 취미 · 동네 가게 소개 | 공개된 홈페이지 주소, 직접 찍은 사진 | 「intro motion graphics」로 찾은 영상 |
| 제품 · 서비스 소개 | 공개된 제품 판매 페이지 주소, 공개 매뉴얼 | 「product launch motion graphics」 |
| 사용법 안내 | 누르는 순서를 적은 메모, 값을 가린 화면 캡처 | 「how-to explainer motion graphics」 |

- **레퍼런스** — 마음에 드는 영상·웹사이트의 링크나 캡처를 주고 「이런 느낌으로」라고 해요. jasonzhu.ai · skillry.dev에서 골라도 돼요
- **자료** — 파일은 작업 폴더에 넣고 「이 폴더의 ○○.pdf 를 읽고」라고 말해요. 웹 페이지는 주소를 붙여 넣고 「이 페이지에 있는 내용만 써」라고 해요. 로고·사진도 폴더에 넣어 주면 AI가 화면을 지어내지 않아요
- **대본** — 있으면 「대본.txt」로 폴더에 넣고 장면마다 한 단락씩 써요. 없으면 자료만 주고 장면표부터 받아요. 어느 쪽이든 **장면표를 먼저 받아 승인**해요
- **장면 3~4개로 짧게** 만들고 두세 번 고쳐 보는 데서 멈춰요

첫 요청은 이렇게 보내요. ○○ 자리를 내 주제·자료·레퍼런스로 바꿔요.

```text
○○ 를 소개하는 30초 모션그래픽을 만들고 싶어. 바로 만들지 말고, 필요한 것을 두 개만 먼저 물어봐줘.
자료: 이 폴더의 ○○ 파일과 ○○ 페이지에 있는 내용만 써줘. 자료에 없는 숫자나 사실은 지어내지 마.
레퍼런스: ○○ 처럼 차분한 느낌으로. 네온 색은 쓰지 말고 글자 크기는 두 가지만.
먼저 장면표(장면 · 화면 · 자막)부터 보여줘. 코드는 내가 승인한 뒤에 써줘.
```

- 공개된 자료만 줘요. 공개되지 않은 실적·고객 이름·가격, 회사 기밀 문서는 넣지 않아요
- 문서 보안(DRM)이 걸린 파일은 AI가 읽지 못해요. 공개용 PDF나 홈페이지 주소를 줘요
- 목소리(내레이션)는 넣지 않고 자막으로 만들어요
- 만든 영상을 회사에서 실제로 쓰고 싶으면, 쓰기 전에 담당 부서에 확인해요

### 본 실습 ② 힉스필드 영상

참고 글과 힉스필드 AI Influencer 페이지를 먼저 훑어봐요. 내 캐릭터가 유행 동작을 따라 하거나 내가 글로 지시한 대로 움직이는 짧은 영상을 만들어요.

**힉스필드는 무료로 거의 한 번밖에 못 만들어요.** 그래서 지시문은 반드시 AI와 먼저 검토한 뒤 넣어요. **고치기는 힉스필드에 넣기 전에 다 끝내요.**

| 순서 | 어디서 | 할 일 | 남는 것 |
|---|---|---|---|
| 1. 기획 | Claude 또는 Gemini | AI가 먼저 묻게 하고 동작을 정해요 | 그림 설명 · 지시문 초안 |
| 2. 캐릭터 | Gemini(그림 만들기) 또는 Claude(도형 캐릭터) | 캐릭터 그림을 만들고, 증상으로 말해 고쳐요 | 캐릭터 그림 한 장 |
| 3. 점검 | Claude 또는 Gemini | 그림을 보여 주고 지시문을 점검받아요 | 최종 지시문 |
| 4. 상태 확인 (선택) | 힉스필드 커넥터를 연결한 Claude, 또는 사이트 화면 | 남은 크레딧과 예상 비용을 확인해요. 커넥터로는 만들지 않아요 | 남은 크레딧 · 예상 비용 |
| 5. 영상 | 힉스필드 사이트 | 그림을 올리고 최종 지시문으로 직접 한 번 만들어 MP4로 내려받아요 | MP4 |

#### 1. 기획

```text
힉스필드로 내 캐릭터가 움직이는 5초 안팎의 짧은 영상을 만들고 싶어. 아래 두 페이지를 먼저 읽어줘.
https://aoworld.tistory.com/171
https://higgsfield.ai/ai-influencer
힉스필드는 한 번밖에 못 만든다고 생각하고, 고치기는 여기서 끝낸 뒤 검토한 지시문을 한 번에 넣으려고 해.
바로 쓰지 말고, 어떤 영상을 만들지 정하는 데 필요한 질문을 두 개만 먼저 해줘.
정해지면 두 가지를 써줘.
1. 캐릭터 그림 설명 — 정면을 보는 전신, 단색 배경
2. 힉스필드에 그대로 넣을 동작 지시문 — 동작은 한두 개, 카메라는 고정, 하지 말 것도 넣어서
유행 동작을 쓰기로 하면 지시문 대신 어떤 동작을 고르면 좋을지 알려줘. 남의 뮤직비디오는 내려받지 않아.
```

AI가 글을 열지 못한다고 하면, 글을 직접 열어 본문을 복사해 붙여 넣어요.

#### 2. 캐릭터 그림

- **Gemini라면:** 같은 대화에서 「위 그림 설명대로 캐릭터 그림을 그려줘」라고 보내고 내려받아요.
- **Claude라면:** Claude는 사진 같은 그림은 못 그리지만, 도형으로 된 귀여운 캐릭터는 그릴 수 있어요. 「위 설명대로 캐릭터를 도형으로 그려서 1024×1024 PNG 로 저장해줘」라고 보내요. 또는 힉스필드 AI 인플루언서로 캐릭터를 만들어도 돼요(무료 몫을 같이 써요).
- 마음에 안 들면 증상으로 말해 고쳐요 — 「얼굴이 옆을 보고 있어. 정면을 보게 다시 그려줘」

#### 3. 지시문 점검

1번 대화창으로 돌아와 그림을 붙이고 보내요.

```text
캐릭터 그림을 붙였어. 이 그림을 보고, 힉스필드에서 한 번에 잘 나오게 지시문을 점검해줘.
얼굴이 바뀌거나 손이 뭉개지기 쉬운 자리, 동작이 너무 많은 자리가 있으면 고쳐서 최종 지시문을 다시 써줘.
```

#### 4. 상태 확인 (선택, Claude)

5주차에 배운 연결을 한 번 더 써 보는 자리예요. 필수는 아니에요.

- Claude 설정의 커넥터에서 **사용자 지정 커넥터 추가** → 이름 `Higgsfield`, 주소 `https://mcp.higgsfield.ai/mcp` → 힉스필드 로그인 창에서 승인해요.
- 방법이 바뀌었거나 막히면 「힉스필드 커넥터를 연결하려는데 지금 방법을 알려 줘」라고 AI에게 묻거나, 화면을 캡처해 붙이고 물어요. 요금제에 따라 사용자 지정 커넥터가 안 될 수 있어요. 그럴 땐 건너뛰어요.

연결되면 1번 대화창에서 보내요.

```text
힉스필드 커넥터로 내 계정을 확인해줘. 아직 아무것도 만들지 마. 크레딧이 드는 일은 하기 전에 비용을 알려 주고 내 답을 기다려.
1. 남은 크레딧이 얼마인지 알려줘
2. 아래 지시문으로 5초 안팎 영상 1개를 만들면 크레딧이 얼마나 드는지, 남은 크레딧으로 만들 수 있는지 알려줘
3. 힉스필드에 준비된 프리셋 가운데 이 장면에 어울리는 것이 있으면 두세 개 골라 이유와 함께 알려줘
(여기에 최종 지시문을 붙여 넣기)
```

연결이 안 되거나 「유료 구독이 필요하다」고 나오면 커넥터는 건너뛰고 힉스필드 사이트 화면에서 남은 크레딧을 직접 봐요. 연결하지 않아도 실습은 그대로 돼요.

#### 5. 힉스필드 사이트에서 만들기

캐릭터 그림을 올리고 최종 지시문으로 직접 만들어요. **검토하지 않은 지시문으로는 누르지 않아요.** 누를 곳을 모르겠으면 화면을 캡처해 대화창에 붙이고 「지금 이 화면인데 다음에 뭘 누르면 돼?」라고 물어요.

- 무료로 만들 수 있는 것은 아주 적어요. 캐릭터와 영상이 같은 무료 몫을 쓸 수 있어요. 누르기 전에 지시문을 한 번 더 봐요
- 캐릭터를 사진으로 만들면 **본인 사진만** 써요. 다른 사람의 사진은 쓰지 않아요
- 동작은 힉스필드의 유행 동작, 직접 찍은 영상, 글로 지시한 동작 중에서 골라요. 남의 뮤직비디오·방송 영상은 내려받지 않아요
- **결제 정보는 넣지 않아요.** 크레딧이 모자라 못 만들었다면 캐릭터 그림과 최종 지시문까지 만든 것으로 충분해요
- 영상을 남에게 보여 줄 때는 **「힉스필드로 만든 AI 영상」**이라고 밝혀요

### 음악 넣기 — 웹게임은 꼭, 모션그래픽은 선택

음악은 바깥 서비스 없이 코드로 만들어요.

- **웹게임** — 효과음·배경음을 꼭 넣어요. 「클릭해서 시작」 뒤에 소리가 나게 해요(몸풀기 지시문에 들어 있어요)
- **모션그래픽** — 선택이에요. 넣으려면 영상 길이에 맞는 배경음을 코드로 만들어 영상에 넣게 해요
- 소리는 이어폰으로 들어 보세요

### 고치기와 되돌리기

다 만들었으면 **마음에 안 드는 곳 하나를 증상으로 말해 고치고, 한 번은 되돌리기도** 해 봐요. 보낼 말은 직접 써요.

| 고른 것 | 증상으로 말하면 |
|---|---|
| 웹게임 | 「주인공이 화면 밖으로 반쯤 나가 있어. 화면 안에서만 움직이게 해줘」 |
| 모션그래픽 | 「12초쯤 제품 이름이 나올 때 글자가 너무 빨리 지나가서 못 읽어. 2초 더 머물게 해줘」 |
| 힉스필드 | 「지시문에 동작이 네 개나 들어 있어. 한 번에 성공하게 두 개로 줄여줘」 |
| 음악 | 「배경음이 효과음보다 커서 효과음이 안 들려. 배경음을 절반으로 줄여줘」 |

### 지킬 것

- 다른 회사의 캐릭터·로고·유명한 곡을 따라 만들지 않아요
- 사람 이름·업무 자료는 넣지 않아요
- 다른 사람의 얼굴로 영상을 만들지 않아요
- 남에게 보여 줄 작품에는 보여 줘도 되는 것만 넣어요. 회사 이야기가 들어간 작품은 공개 링크로 올리지 않아요

### 남에게 보여 주기 (선택)

만든 게임 파일을 가족이나 친구에게 보내 해 보게 하면 재미있어요. 그때 쓸 제목·설명을 AI에게 제안받아 보세요.

```text
이 작품을 다른 사람에게 보여 주려고 해. 바로 정하지 말고 아래 두 가지를 두 개씩 제안해줘. 내가 고를게.
1. 제목 — 20자 안쪽
2. 설명 — 서식 없이 300자 안쪽. 무엇을 만들었고, 어떤 AI로 어떻게 만들었는지. 웹게임이면 게임하는 방법(목표 · 조작키 · 점수 얻는 법 · 끝나는 조건)을 꼭 넣어줘
```

받은 설명은 내가 읽고 고쳐요. 웹게임 설명은 **해 보는 사람이 설명만 읽고 바로 시작할 수 있어야** 해요.
