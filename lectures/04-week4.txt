## 이번 주 목표

- 내 일에 필요한 자료를 AI가 인터넷에서 찾아오게 하고, 쓰기 전에 걸러낸다
- 그 과정을 Skill로 저장하고, 평일 아침 정해진 시각에 사람 없이 돌게 한다
- 3주차에 낸 자동화 아이디어 하나를 Skill로 구체화한다

## 지난주까지는

AI와 대화하고, 파일을 맡기는 기본 사용법을 익혔어요. 이번 주부터는 AI 도구가 가진 기능을 하나씩 익혀 가요. 그 첫 번째가 **Skill과 예약**이에요.

## 1. Skill과 예약이란

| | 무엇인가 |
|---|---|
| Skill | 일하는 절차와 규칙에 이름을 붙여 저장한 것. 매번 지시문을 다시 쓰지 않고 이름만 부르면 같은 방법으로 일해요 |
| 예약 작업 | 정해진 시각에 같은 지시를 사람 없이 다시 실행하는 기능 |

**도구마다 이름이 달라요**

| | Claude | Gemini |
|---|---|---|
| 절차를 저장해 두는 것 | **Skill** | **Gem** (지침과 참고 파일을 저장해 둔 나만의 도우미) |
| 정해진 시각에 돌리기 | **예약 작업** (데스크톱 앱) | **예약된 작업** (유료 요금제 Google AI Pro 이상) |
| 결과가 남는 곳 | 연결한 폴더에 파일로 | 대화창 (필요하면 엑셀·구글 시트로 내보내기) |

> Gemini 무료 요금제라면 예약은 쓸 수 없어요. 대신 만들어 둔 Gem을 매일 아침 열고 한 줄만 보내면 돼요. 이번 주 핵심은 「절차를 저장해 두고 이름만 부르기」라서 그것만으로도 충분해요.

## 2. 꼭 지킬 것 네 가지

| 지킬 것 | 왜 |
|---|---|
| 검색어에 회사·거래처·사람 이름을 넣지 않아요 | 검색어는 그대로 외부로 나가고, 예약을 걸면 매일 아침 나가요 |
| 확인은 사람이 해요 | AI가 단 출처와 숫자도 틀릴 수 있어요. 원문을 직접 열어 본 것만 「확인」이에요 |
| 예약 결과는 초안이에요 | 아무도 안 볼 때 돌기 때문에, 사람이 확인하기 전에는 밖으로 내보내지 않아요 |
| 예약 폴더는 그 일 전용이에요 (Claude) | 예약은 폴더의 파일을 확인 없이 읽어요. 그 일에 필요한 파일만 둬요 |

## 3. Skill은 작업 매뉴얼이에요

AI에게 같은 일을 맡길 때마다 형식·말투·하지 말 것을 다시 설명하고 있다면, 그 설명을 Skill로 만들 때예요.

Skill은 특정 일을 위한 **작업 매뉴얼**이에요. 신입에게 말로만 시키지 않고 매뉴얼과 양식을 건네듯, 한 번 가르쳐 두면 다음부터는 AI가 그대로 일해요.

### 지침 · 메모리 · Skill은 무엇이 다른가

| 구분 | 담는 것 | 비유 |
|---|---|---|
| 지침 (2주차에 적어 둔 칸) | 언제나 지킬 규칙 | 매일 하는 잔소리 |
| 메모리 | 기억해 둘 상황 | 지난번 대화의 기억 |
| Skill (Gemini는 Gem) | 반복되는 일의 절차 | 레시피 |

모든 걸 지침에 넣으면 일이 늘수록 지침이 길어지고 무거워져요. **일마다 나눠 두고 필요할 때만 꺼내 쓰는 게 Skill**이에요.

### Skill은 폴더 하나예요 (Claude)

| 파일 | 꼭 있어야 하나 | 하는 일 |
|---|---|---|
| SKILL.md | 꼭 | 이름·설명과 일하는 절차 |
| 참고 자료 | 필요할 때 | 긴 설명이나 예시 |
| 스크립트 | 필요할 때 | 매번 똑같아야 하는 계산·서식 |
| 양식 파일 | 필요할 때 | 결과물의 틀 |

이 파일들은 **직접 만들지 않아도 돼요.** AI에게 만들어 달라고 하고, 고칠 곳만 말하면 돼요.

SKILL.md는 두 부분이에요.

- **맨 위: 이름과 설명.** 이 Skill을 언제 쓰는지 적어요. AI가 Skill을 고를 때 보는 검색 키워드 역할이라, 내가 실제로 할 말이 들어 있어야 제때 불려 나와요.
- **아래 본문: 절차.** 어떻게 일하는지 단계별로 적은 내용이에요.

### AI는 Skill을 이렇게 써요

AI는 설치된 Skill의 설명만 먼저 훑어보고, 맞는 Skill을 찾으면 그때 본문과 필요한 파일을 열어요. 회의에 자료 뭉치 대신 요약본만 들고 가는 전문가와 같아서, Skill을 많이 만들어도 가벼워요.

부르는 방법은 두 가지예요.

- 평소처럼 일을 시키면 AI가 알아서 맞는 Skill을 꺼내요.
- 이름으로 직접 부를 수도 있어요. Claude는 이름 앞에 슬래시(/)를 붙여요. (예: `/부서자료`)

Gemini의 Gem은 왼쪽 목록에서 그 Gem을 골라 대화를 시작하면 돼요.

### 비슷한 이름과 구분하기

| 이름 | 무엇인가 |
|---|---|
| Skill / Gem | 일하는 방법. 매뉴얼 |
| 커넥터 (MCP) | 노션·슬랙 같은 외부 도구로 이어 주는 연결선 |
| 서브에이전트 | 큰 일을 따로 맡아 결과만 가져오는 외주 전문가 |

### 잘 만들고 키우는 요령

- **만들 때도 말로.** 방금 한 작업을 Skill로 만들어 달라고 하면, AI가 형식과 항목을 묻고 초안을 써 줘요.
- **SKILL.md는 가볍게.** 안내 데스크처럼 짧게 두고, 긴 자료는 참고 파일로 빼요.
- **같아야 하는 것은 고정.** 매번 똑같아야 하는 계산과 서식은 스크립트로 둬요.
- **실수는 기록.** 틀렸던 것은 오답 노트 파일에 쌓아 두면 같은 실수가 줄어요.
- **쓰면서 고치기.** 결과가 아쉬우면 고친 내용을 Skill에 반영하게 해요. 쓸수록 Skill이 자라요.
- **중요한 일은 사람이 마지막에.** 계약·채용처럼 중요한 일은 결과를 사람이 꼭 검토해요.

### 무엇부터 만들까

매주 반복하는 일 하나면 충분해요. 주간 보고서, 견적서, 회의록, 고객 리뷰 답변처럼 형식이 정해진 일이 좋아요. 만드는 데는 10분이면 되고, 아끼는 시간은 매주 쌓여요.

### 시작하기 전에

**Claude라면:** 「AI실습」 폴더 아래에 `4주차` 폴더를 새로 만들어 Cowork에 연결해 두세요. 연결하는 방법은 3주차 1번과 같아요.

**Gemini라면:** 새 대화를 열면 돼요. 아래 지시문에서 「작업 폴더에 ○○를 만들어줘」는 「○○ 내용을 만들어서 보여줘」로, 「output 폴더에 저장해줘」는 「엑셀 파일로 만들어줘」로 바꿔 읽으세요. (3주차의 바꿔 읽기 표와 같아요)

> **Skill이나 예약을 쓸 수 없으면:** 요금제나 환경 때문에 안 되는 단계는 지시문을 그때그때 다시 보내는 것으로 대신해도 괜찮아요. 「저장해 두고 다시 쓰는 감각」만 익히면 돼요.

### 실습 1. 내 일 자료를 매일 받아 보기

#### 1단계. 연결 확인 (Claude)

```text
이 폴더 경로 알려주고, 어떤 파일이 있는지 보여줘. 아직 아무것도 고치거나 만들지 마.
```

알려 준 경로가 방금 만든 `4주차` 폴더이고 빈 폴더라고 나오면 연결된 거예요.

#### 2단계. 내 일 프로필 만들기

AI에게 `부서프로필.md`를 만들게 해요. 사람마다 알아야 할 것이 다르니, 내 관심 주제는 Skill이 아니라 이 파일에 둬요. ○○ 자리를 내 일로 바꿔 보내세요.

```text
작업 폴더에 부서프로필.md 를 만들어줘. 아직 검색은 하지 마.

- 나는 ○○ 부서에서 ○○ 업무를 해.
- 매일 알고 싶은 것은 ○○, ○○, ○○ 야.
- 주제마다 검색 키워드를 3개씩 만들어줘. 회사 이름·거래처 이름·사람 이름 대신 업종·품목·제도 이름으로 써줘.
- 주제마다 먼저 볼 출처(정부·공공기관·협회·공식 발표)를 적어줘.
- 다 만들면 내가 고칠 수 있게 내용을 보여줘.
```

주제는 하는 일에 따라 이런 것들이에요. 영업은 공공 입찰 공고, 마케팅은 업계 캠페인 사례, 경영지원은 노무·세무 법령 개정, IT는 보안 취약점 공지, 물류는 운임 지수. 경영지원 일이라면 프로필이 대략 이런 모양이 돼요.

| 주제 | 검색 키워드 | 먼저 볼 출처 |
|---|---|---|
| 노무 관련 법령 개정 | 근로기준법 개정, 최저임금 고시, 고용노동부 행정해석 | 고용노동부, 국가법령정보센터 |
| 중소기업 지원사업 공고 | 중소기업 지원사업 공고, 정보통신 분야 바우처, 고용지원금 | 기업마당, 중소벤처기업부 |

받은 프로필을 직접 읽고 고칠 곳을 말하세요. **주제는 3~5개**가 적당해요. 너무 많으면 매일 결과가 길어져 읽지 않게 돼요.

회사 이름·거래처 이름·사람 이름이 들어 있으면 **지금 빼세요.** 이 프로필이 매일 아침 검색어가 돼요.

#### 3단계. 손으로 한 번 돌리기

Skill로 만들기 전에 손으로 한 번 돌려 봐야 무엇을 규칙으로 넣을지 알 수 있어요. (오늘 날짜를 넣어 파일 이름을 정해요)

```text
작업 폴더의 부서프로필.md 를 읽고, 주제마다 최근 7일 안에 나온 자료를 인터넷에서 찾아줘.

- 검색어는 프로필의 검색 키워드만 써줘. 회사 이름·거래처 이름·사람 이름은 넣지 마.
- 자료마다 출처 링크를 꼭 달아줘. 링크가 없는 내용은 넣지 마.
- 찾은 게 없는 주제는 지어내지 말고 「새 자료 없음」이라고 한 줄 적어줘.
- 결과는 output 폴더에 부서자료_오늘날짜.xlsx(예: 부서자료_20261103.xlsx)로 저장해줘.
- 열은 날짜 / 주제 / 제목 / 한 줄 요약 / 게시일 / 출처URL / 확인여부 / 비고 로 해줘.
- 확인여부는 전부 「확인 필요」로 둬. 확인은 내가 해.
```

답에 **출처 링크가 붙었는지** 먼저 보세요. 링크가 없으면 검색을 하지 않고 원래 알던 것으로 답한 거예요.

> **회사 PC라면:** 문서 보안(DRM)이 있으면 결과 엑셀을 엑셀로 저장하는 순간 AI가 다시 못 읽을 수 있어요. 3주차처럼 「엑셀 프로그램을 실행하지 말고 파일을 직접 만들어줘」를 덧붙이고, 결과 파일은 열어 보기만 하고 저장하지 말고 닫으세요.

#### 4단계. 원문 열어 거르기 (2건 이상)

먼저 확인할 거리를 AI에게 표시하게 해요. 아래 「숫자·날짜·법령 조항·기관 이름」은 예시예요. 내 일에서 틀리면 곤란한 것으로 바꿔 보내세요.

| 하는 일 | 이렇게 바꿔 써요 |
|---|---|
| 영업 | 공고 마감일 · 사업 금액 · 발주 기관 |
| 마케팅 | 캠페인 기간 · 성과 수치 · 매체 이름 |
| 경영지원 | 법령 조항 · 시행일 · 고시 금액 |
| IT | 취약점 번호 · 영향받는 버전 · 패치 배포일 |
| 물류 | 운임 지수 · 적용 기간 · 노선 |

```text
부서자료_○○○○○○○○.xlsx 에서 숫자·날짜·법령 조항·기관 이름이 들어 있는 행을 골라 행 번호와 함께 목록으로 보여줘. 아직 아무것도 고치지 마.
```

그중 **2건 이상을 골라 링크를 직접 열고** 확인해요.

- 링크가 열렸나요?
- 그 페이지에 실제로 그 내용이 있나요?
- 게시일이 맞나요? 최근 7일 안이 맞나요?

틀린 것을 하나라도 잡아냈다면, 그게 이번 실습에서 가장 중요한 결과예요. 실패가 아니라 잘 거른 거예요.

#### 5단계. Skill로 저장하고 새 대화에서 불러 보기

**Claude라면:** 4단계까지 한 그 대화에서 아래 지시를 보내요.

```text
방금 부서 자료를 찾아 엑셀로 만든 과정을, 내일부터 같은 방법으로 다시 돌릴 수 있게 Skill 로 만들어줘.

- 이름은 「부서자료」로 해줘.
- 주제와 검색 키워드는 Skill 에 적지 말고, 돌 때마다 작업 폴더의 부서프로필.md 에서 읽게 해줘.
- 검색어에는 회사 이름·거래처 이름·사람 이름을 넣지 말고 프로필의 검색 키워드만 쓰게 해줘.
- 확인여부는 전부 「확인 필요」로 두게 해줘. 확인은 내가 해.
- 찾은 게 없는 주제는 지어내지 말고 「새 자료 없음」이라고 적게 해줘.
- output 폴더의 최근 7일 결과 파일과 출처URL 이 같은 자료는 빼게 해줘.
- 결과는 output 폴더에 저장만 하고, 메일 보내기·파일 올리기·지우기는 하지 말게 해줘.
```

만든 Skill에 위 규칙이 다 들어갔는지 같은 대화에서 확인해요.

```text
방금 만든 부서자료 스킬의 내용을 그대로 보여줘. 아직 아무것도 고치지 마.
```

규칙(확인 필요 · 고유명사 금지 · 새 자료 없음 · 최근 7일 중복 제외 · 저장만)이 모두 있는지 봐요. 빠진 게 있으면 「이 스킬에 ○○ 규칙을 넣어줘」로 고쳐요.

```text
방금 만든 부서자료 스킬은 어디에 저장됐어? 화면에서 확인하는 곳과, 다음에 다시 부르는 방법을 알려줘.
```

**그다음 새 대화창을 열고 불러 봐요.** 만든 대화 안에서는 AI가 앞의 일을 기억하니까, 새 대화에서 불러 봐야 Skill만으로 도는지 알 수 있어요.

```text
부서자료 스킬로 오늘 자료 정리해줘.
```

같은 날 다시 부른 거라 3단계에서 찾은 자료는 빠져야 정상이에요. 같은 자료가 다시 나오면 Skill을 고치고 다시 불러요.

시험용으로 만든 Skill을 끄는 방법이 필요하면 이렇게 물어보세요.

```text
부서자료 스킬을 끄거나 다시 켜려면 어떻게 해?
```

**Gemini라면: Gem으로 저장해요.** Gemini는 폴더의 파일을 읽지 못하니, 프로필 내용을 Gem의 참고 파일로 넣어 둬요.

1. 2단계에서 받은 프로필 내용을 메모장에 붙여 `부서프로필.txt`로 저장해요.
2. Gemini 왼쪽 메뉴에서 **Gem 만들기**(또는 Gem 관리자 → 새 Gem)를 눌러요.
3. 이름은 `부서자료`로 하고, **지침** 칸에 아래 내용을 붙여 넣어요.
4. **지식(파일)** 칸에 `부서프로필.txt`를 올리고 저장해요.

```text
너는 내 일에 필요한 최신 자료를 매일 찾아 정리하는 도우미야.
- 주제와 검색 키워드는 첨부한 부서프로필.txt 에서 읽어.
- 검색어에는 회사 이름·거래처 이름·사람 이름을 넣지 말고 프로필의 검색 키워드만 써.
- 주제마다 최근 7일 안에 나온 자료만 찾아. 자료마다 출처 링크를 꼭 달고, 링크가 없는 내용은 넣지 마.
- 찾은 게 없는 주제는 지어내지 말고 「새 자료 없음」이라고 적어.
- 결과는 표로 정리해. 열은 날짜 / 주제 / 제목 / 한 줄 요약 / 게시일 / 출처URL / 확인여부 / 비고.
- 확인여부는 전부 「확인 필요」로 둬. 확인은 내가 해.
- 메일 보내기나 다른 곳에 올리기는 하지 마.
```

저장한 Gem을 열고 `오늘 자료 정리해줘`라고 보내 잘 도는지 봐요.

> Gemini는 지난 결과 파일을 볼 수 없어서 「최근 7일 중복 제외」는 자동으로 안 돼요. 겹치는 자료는 내가 확인할 때 걸러 내면 돼요.

#### 6단계. 평일 아침 예약 걸고 등록 확인하기

**Claude라면:** Skill을 만든 그 대화에서 보내요.

```text
평일(월~금) 아침 11시에 부서자료 스킬을 실행해서 결과를 이 작업 폴더의 output 폴더에 저장해줘.
```

PC나 앱이 꺼져 있을 때 예약이 어떻게 되는지는 도구마다 달라요. 바로 물어 두세요.

```text
PC 나 앱이 꺼져 있으면 이 예약은 어떻게 돼? 켜면 다시 도는지, 그냥 건너뛰는지 알려줘.
```

예약이 제대로 걸렸는지 화면에서 직접 확인해요.

```text
지금 나한테 등록된 스킬과 예약 작업을 모두 알려줘. 각각 화면의 어디에서 볼 수 있는지(메뉴 위치)와, 예약은 실행 시각·실행할 스킬·저장 폴더를 어디서 확인하는지 알려줘. 예약을 잠시 멈추는 방법도 알려줘. 아직 아무것도 고치거나 지우지 마.
```

알려 준 곳을 직접 열어 아래 네 가지가 맞는지 봐요.

- 부서자료 스킬이 목록에 있나요?
- 예약 실행 시각이 평일 11시인가요?
- 예약이 실행하는 것이 부서자료 스킬인가요?
- 결과를 저장하는 곳이 `4주차` 폴더의 output 폴더인가요?

틀린 곳이 있으면 「이 예약의 ○○을 ○○로 바꿔줘」로 고쳐요.

**Gemini라면 (Google AI Pro 이상):** 부서자료 Gem 대화에서 이렇게 보내요.

```text
평일(월~금) 아침 11시마다 오늘 자료를 정리해줘.
```

Gemini가 예약을 확인해 주면, 웹에서는 왼쪽 **설정 및 도움말 → 예약된 작업**에서 실행 시각과 지시 내용을 확인하고 멈추거나 지울 수 있어요. 예약은 정한 시각 기준 한 시간 안에 돌아요.

**Gemini 무료라면:** 예약은 건너뛰고, 내일 아침에 부서자료 Gem을 열어 `오늘 자료 정리해줘` 한 줄만 보내 보세요.

결과는 다음 날 아침 9단계에서 확인해요. 기다리는 동안 실습 2로 넘어가세요.

### 실습 2. 내 일 아이디어 하나를 Skill로 만들기

#### 7단계. 3주차 아이디어 5개를 자동화 단계로 나누기

**Claude라면:** 「AI실습」 아래에 `공통-내업무` 폴더를 하나 더 만들고, 3주차 output 폴더의 `3주차-실습결과.xlsx`를 복사해 넣어요. **새 대화창**에서 이 폴더를 연결해요. 이 폴더는 다음 주에도 이어 쓰니 주차 이름을 붙이지 않아요.

> `4주차` 폴더에 넣지 마세요. 그 폴더는 매일 예약이 읽는 전용 폴더예요.

**Gemini라면:** 새 대화를 열고 `3주차-실습결과.xlsx`를 첨부해요.

`공통-내업무` 폴더(또는 Gemini 대화)와 7~8단계를 한 대화창은 **지우지 마세요.** 내 일 자동화는 이번 주로 끝나지 않고 마지막 주까지 이어져요.

3주차 자료가 없어도 괜찮아요. 아래 지시를 먼저 보내고, 그다음 지시의 첫 줄을 「방금 받은 아이디어 5개를 읽어줘」로 바꿔 보내세요. 일을 설명할 때 회사·고객 이름과 금액은 적지 않아요.

```text
나는 ○○팀에서 ○○ 업무를 해. 매주·매달 비슷하게 되풀이하는 일 중에서 AI로 줄일 수 있는 아이디어 5개를 줘. 아직 파일은 만들지 마.
```

이제 아이디어 5개를 자동화 단계로 나눠요.

```text
3주차-실습결과.xlsx 의 「자동화 아이디어」 시트를 읽어줘. 아직 아무것도 고치지 마.
아이디어 5개를 하나씩, 아래 네 가지 중 어디까지 자동화할 수 있는지 나눠줘.

- 매번 지시: 그때그때 대화창에 지시해서 쓴다
- Skill: 절차를 Skill 로 저장해 이름만 부른다
- Skill + 예약: 정해진 시각에 사람 없이 돌린다
- 사람이 한다: 판단이 많거나 결과가 확인 없이 밖으로 나가서 AI에게 맡기지 않는다

근거는 얼마나 자주 하는지, 들어오는 자료 형식이 매번 같은지, 결과를 확인하기 쉬운지, 결과가 확인 없이 밖으로 나가는지로 들어줘.
```

AI가 나눈 걸 그대로 받지 말고, **내 일을 아는 내가 고쳐요.** 그다음 저장해요.

```text
○번은 「○○」로 바꿔줘. 이유는 ○○야.
정리한 결과를 output 폴더의 공통-내업무자동화.xlsx 에 「분류」 시트로 저장해줘. 열은 번호 / 아이디어 / 자동화 단계 / 근거 / 내가 고친 곳 으로 해줘.
```

`공통-내업무자동화.xlsx`는 다음 주에도 이어서 써요. 새 파일을 만들지 말고 이 파일에 시트를 더해 가세요.

#### 8단계. 하나 골라 다섯 칸 설계하고 Skill로 만들기

「Skill」이나 「Skill + 예약」으로 나눈 것 중 **효과가 가장 클 것 하나**를 골라요. 부서자료 Skill이 잘 돈 건 입력·절차·결과·확인 자리·넣지 말 것이 분명했기 때문이에요. 내 일도 이 다섯 칸을 먼저 채워요.

```text
「분류」 시트의 ○번 아이디어를 Skill 로 만들려고 해. 만들기 전에 설계부터 같이 정리하자.

- 입력: 무엇을 어디에 넣으면 도는가
- 절차: 어떤 순서로 처리하는가 (5단계 안팎)
- 결과: 무엇을 어떤 형식으로 어디에 남기는가
- 사람이 확인할 자리: 결과의 어느 칸을 사람이 보고 채우는가
- 넣지 말 것: 이 일에서 AI에게 넘기면 안 되는 정보

내 일에 대해 모르는 부분은 지어내지 말고 나한테 물어봐.
```

AI가 묻는 것에 답하며 다섯 칸을 채워요. 다 채웠으면 저장해요.

```text
정리한 설계를 공통-내업무자동화.xlsx 에 「설계」 시트로 넣어줘. 「Skill + 예약」으로 나눈 일이면 예약 지시문(언제, 어느 Skill 로, 어디에)도 한 줄 적어줘.
```

같은 대화에서 Skill로 만들어요. ○○ 자리에 Skill 이름을 넣으세요. (Gemini는 「Skill」을 「Gem 지침」으로 바꿔 받아서, 5단계처럼 새 Gem에 붙여 넣으면 돼요)

```text
「설계」 시트대로 이 일을 Skill 로 만들어줘.

- 이름은 「○○」로 해줘.
- 사람이 확인할 자리는 「확인 필요」로 남기게 해줘.
- 자료에 없는 내용은 지어내지 말고 「확인 필요」로 표시하게 해줘.
- 결과는 output 폴더에 저장만 하고, 메일 보내기·파일 올리기·지우기는 하지 말게 해줘.
```

```text
방금 만든 ○○ 스킬의 내용을 그대로 보여줘. 아직 아무것도 고치지 마.
```

규칙(확인 필요 · 지어내지 않기 · 저장만)이 모두 들어 있는지 봐요. 빠진 게 있으면 「이 스킬에 ○○ 규칙을 넣어줘」로 고쳐요.

**예약은 걸지 않아요.** 「Skill + 예약」으로 나눈 일이라도 예약은 실제 자료가 준비된 뒤에 걸어요.

#### 9단계. (다음 날 아침) 예약 결과 확인

Claude는 `4주차` 폴더의 output 폴더에 새 결과 파일이 생겼는지, Gemini는 예약된 작업의 결과(대화창·알림)를 보고 아래 네 가지를 확인해요.

- [ ] 확인여부가 전부 「확인 필요」인가요?
- [ ] 출처 링크가 모든 행에 붙었나요?
- [ ] 3단계에서 찾은 자료가 다시 나오지 않았나요? (Claude)
- [ ] 새 자료가 없는 주제에 「새 자료 없음」이 적혔나요?

예약이 돌지 않았다면 무엇이 보였는지(오류 문구, PC가 꺼져 있었는지 등)를 메모해 두세요. 그것도 배운 거예요. 예약은 평일에만 도니까, 금요일에 걸었다면 결과는 월요일에 나와요.

## 끝나고 나서도: Skill은 쓰면서 고쳐요

Skill은 한 번 만들고 끝나지 않아요. 쓰다가 아쉬운 점이나 더 넣을 규칙이 보이면 그때그때 이렇게 말해 고쳐 가며 쓰세요.

```text
○○ 스킬을 쓰다 보니 ○○ 부분이 아쉬웠어. 앞으로는 ○○ 하도록 스킬을 수정해줘.
```

부서자료 Skill도, 내 일 Skill도 같은 방법으로 고쳐요. 고친 뒤에는 새 대화창에서 한 번 불러 보고 바뀐 대로 도는지 확인하세요. Gemini는 Gem 편집에서 지침을 고치면 돼요.

막히는 곳이 있으면 화면을 캡처해서 물어보세요.
