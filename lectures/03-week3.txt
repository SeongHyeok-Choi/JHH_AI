## 1. 엑셀 파일을 AI에게 맡기는 방법

### 실습 폴더부터 만들어요

「내 문서」 안에 `AI실습` 폴더를 만들고, 그 안에 `3주차` 폴더를 만들어 두 실습 파일을 넣어요. 경로가 짧고 한눈에 보이는 자리가 좋아요.

### Claude를 골랐다면: Cowork에 폴더 연결하기

Claude는 **Cowork**에 폴더를 연결해서 써요. 파일을 대화창에 하나씩 올리지 않고, 파일이 든 폴더를 연결해 두면 AI가 그 폴더의 파일을 직접 열고, 만든 결과도 그 폴더에 저장해요.

- 표 작업은 매달 같은 자료가 다시 와요. 그때마다 파일을 다시 올리지 않아도 돼요.
- 결과가 내 폴더에 파일로 남아요. 화면에서 복사해 옮기는 일이 없어져요.
- 원본·정리본·결과물이 한 폴더에 모이니 검산할 때 대조하기 쉬워요.

**연결하는 순서**

1. Claude **데스크톱 앱**을 열어요. 웹 브라우저에서는 폴더를 읽지 못해요.
2. 왼쪽 위 **채팅 및 Cowork**를 누르고, 입력창의 **채팅 | Cowork**에서 **Cowork**를 골라요.
3. 입력창 아래 **프로젝트 또는 폴더**를 누르고 **폴더 추가**를 골라요. 프로젝트는 만들지 않아도 돼요.
4. 방금 만든 `3주차` 폴더를 골라 **폴더 선택**을 눌러요.
5. 「파일을 변경하도록 허용하시겠습니까?」 창이 뜨면 폴더 이름을 확인하고 **허용**을 눌러요. **항상 허용은 누르지 않아요** (아래 설명).
6. 입력창 아래에 폴더 이름이 보이면 연결된 거예요.

> 화면과 버튼 이름은 자주 바뀌어요. 다르게 보이면 흐름만 따라가세요. 1주차 참고 동영상의 4분 구간에 폴더를 추가하는 장면이 나와요.

> **참고:** Claude 데스크톱 앱에는 개발자용 **Claude Code**도 있어요. 엑셀 정리도 되지만 명령을 실행해도 되는지 묻는 창이 자주 뜨고 설명이 코드 위주라, 처음이라면 Cowork로 하세요.

### Gemini를 골랐다면: 파일 첨부하고 결과 파일 내려받기

Gemini는 대화창에 **엑셀 파일을 첨부**해서 써요. 결과는 「엑셀 파일로 만들어줘」라고 하면 내려받을 수 있는 파일로 만들어 줘요.

1. Gemini 앱에서 새 대화를 열어요.
2. 입력창의 **+** (파일 추가) 버튼으로 실습 파일 두 개를 첨부해요.
3. 지시를 보내요. 결과가 표로 나오면 「엑셀(.xlsx) 파일로 만들어줘」라고 덧붙여 내려받아요.
4. 다음 단계에서 그 결과 파일을 써야 하면 **내려받은 파일을 다시 첨부**해요.

> Gemini에도 폴더를 연결해서 일을 맡기는 기능이 나오고 있지만, 아직 일부 유료 요금제와 영어에서만 쓸 수 있어요. 이번 실습은 첨부 방식으로 충분해요.

**이번 주 지시문을 Gemini에서 쓸 때는 이렇게 바꿔 읽으세요**

| 지시문에 있는 말 | Gemini에서는 |
|---|---|
| 이 폴더의 ○○.xlsx | 첨부한 ○○.xlsx |
| output 폴더에 ○○.xlsx 로 저장해줘 | ○○.xlsx 라는 엑셀 파일로 만들어줘 (내려받기) |
| ○○.xlsx 에 「△△」 시트를 넣어줘 | 앞의 파일을 다시 첨부하고, 「△△」 시트를 더한 엑셀 파일로 다시 만들어줘 |

### 연결이 됐는지 먼저 확인하세요

정리를 시키기 전에 이 한 줄부터 보내 보세요. (Gemini는 「이 폴더에」 대신 「첨부한 파일이」)

```text
이 폴더에 어떤 파일이 있고 각각 어떤 내용인지 한 줄씩 정리해줘.
```

목록에 `3주차-실습데이터.xlsx`가 보이면 준비된 거예요. 「파일을 찾을 수 없다」고 하면 폴더를 잘못 골랐거나, 실습 파일을 그 폴더에 넣지 않았거나, 데스크톱 앱이 아닌 웹에서 열고 있는 거예요.

### 결과를 어디에, 어떻게 저장할지도 말하세요 (Claude)

```text
정리한 결과는 원본을 고치지 말고 같은 폴더 안 output 폴더에 새 파일로 저장해줘.
```

원본을 남기려는 거예요. 검산할 때 대조할 게 있어야 하니까요. Gemini는 원래 첨부한 파일이 그대로 남아 있으니 이 말은 안 해도 돼요.

> **회사 PC라면:** 회사에 문서 보안(DRM)이 있으면 엑셀로 저장하는 순간 파일이 암호화되어 AI가 다시 못 읽기도 해요. 그럴 땐 「엑셀 프로그램을 실행하지 말고 파일을 직접 쓰는 방법(예: 파이썬 라이브러리)으로 만들어줘」를 덧붙이고, AI가 만든 파일은 열어 보기만 하고 저장하지 말고 닫으세요.

### 폴더를 연결할 때 조심할 것 (Claude)

폴더를 읽게 하면 AI가 내 파일을 직접 고칠 수 있어요. 되돌리기가 안 돼요.

- **원본이 아니라 사본**을 둔 폴더를 지정하세요.
- 그 폴더에 **이번 작업과 상관없는 파일을 두지 마세요.** 지정한 폴더는 전부 읽혀요.
- 권한을 묻는 창이 뜨면 **무엇을 허용하는지 읽고** 누르세요.

폴더에서 읽는다고 내용이 내 PC 안에만 머무는 건 아니에요. 파일 내용은 처리를 위해 AI 서비스로 전달돼요. 첨부 방식(Gemini)도 마찬가지예요. 그래서 아래 6번(넣기 전에 지울 것)은 어느 도구든 똑같이 적용돼요.

### 「항상 허용」은 누르지 않아요 (Claude)

폴더를 연결하면 AI가 파일을 고치거나 명령을 실행하기 전에 허용할지 묻는 창이 떠요. 여기에는 대개 「이번만 허용」과 「항상 허용」이 함께 있어요. 귀찮다고 「항상 허용」을 누르면 그다음부터는 묻지 않고 실행해요.

| 매번 묻게 둘 것 | 이유 |
|---|---|
| 파일 삭제·덮어쓰기 | 되돌리기가 안 돼요. 휴지통에 남지 않는 경우도 있어요 |
| 연결한 폴더 밖의 파일 | 정리하지 않은 원본이 거기 있어요 |
| 명령 실행 | 무엇을 하는 명령인지 읽고 나서 허용해요 |
| 메일 보내기·파일 올리기처럼 밖으로 내보내는 일 | 나간 건 되돌릴 수 없어요 |

## 2. 표 데이터 요약

긴 표를 그대로 주고 "요약해줘"라고 하면 쓸모없는 답이 나와요. **무엇을 알고 싶은지**를 말해야 해요.

```text
이 폴더의 3주차-실습데이터.xlsx 의 「지출내역」 시트는 1분기(1~3월) 부서별 지출 내역이야.
부서별 합계와 전월 대비 증감을 표로 정리하고, 증가폭이 큰 3개 부서만 따로 짚어줘.
```

## 3. 수식·피벗테이블 추천 받기

수식을 물어볼 때는 **표 구조를 먼저 설명**해야 해요. 실습 파일의 「지출내역」 시트라면 이렇게 써요.

```text
「지출내역」 시트에서 A열은 일자, B열은 부서, C열은 항목, D열은 금액이야. 열 이름은 3행이고 데이터는 4행부터 39행까지야.
부서별 1월 금액 합계를 구하는 수식을 알려줘. 엑셀 2019에서 동작해야 해.
```

다른 파일로 한다면 이 지시를 그대로 붙여 넣지 마세요. 시트 이름, 열마다 무엇이 들었는지, 열 이름이 있는 행, 데이터가 시작하고 끝나는 행을 내 파일을 열어 보고 바꿔서 넣으세요. 위치를 틀리게 알려 주면 AI는 그 위치대로 엉뚱한 칸을 더하는 수식을 줘요. 오류 없이 숫자가 나오니 검산하기 전에는 알아채기 어려워요.

**빠뜨리기 쉬운 것**

- 엑셀 버전: 구버전에서 안 되는 함수가 있어요
- 시작 행 번호: 머리글이 1행인지 3행인지
- 빈 칸과 오류 값을 어떻게 처리할지

### 피벗테이블

만들어 달라고 하는 대신 **어떻게 만들지 물어보세요.**

```text
이 데이터로 부서별·월별 지출을 보려면 피벗테이블 행·열·값에 무엇을 넣어야 해?
```

## 4. 차트 구성

차트는 무엇을 보여 주려는지에 따라 종류가 달라져요.

| 보여 주려는 것 | 맞는 차트 |
|---|---|
| 항목 간 크기 비교 | 막대 |
| 시간에 따른 변화 | 선 |
| 구성 비율 | 원, 누적 막대 |
| 두 값의 관계 | 산점도 |

```text
부서별 지출을 비교해서 부서장 보고에 넣으려고 해. 어떤 차트가 맞고, 축과 정렬은 어떻게 하는 게 좋아?
```

## 5. 표는 반드시 검산해요

AI가 만든 표에서 합계와 건수가 틀리는 경우가 흔해요.

- **행 수**가 원본과 맞나요? (정리하다가 사라진 행이 없나요)
- **합계**가 원본 합계와 같나요?
- **샘플 3~5행**을 원본과 눈으로 대조해요.

수식을 받았다면 **이미 답을 아는 값으로 한 번 돌려 보세요.** 가장 빠른 검증법이에요.

### 여러 파일을 엮어 문서 만들기

파일 여러 개를 엮어 문서를 만들게 할 수도 있어요. 엑셀 두 개를 보며 Word 보고서를 쓰는 일이 한 번의 지시로 끝나요. (`3주차-실습결과.xlsx`는 아래 따라 해 보기 3단계에서 만드는 파일이에요.)

```text
output 폴더의 3주차-실습결과.xlsx 「정리 후」 시트와 3주차-부서별예산표.xlsx 「부서별예산」 시트를 읽어줘.
부서별로 1분기 예산, 실제 지출, 집행률(지출 ÷ 예산)을 표로 만들고, 예산을 넘긴 달이 있는 부서를 짚어서 부서장 보고용 1장짜리 Word 문서로 output 폴더에 저장해줘.
숫자는 두 파일에 있는 값만 쓰고, 표 아래에 각 숫자를 어느 파일 어느 시트에서 가져왔는지 적어줘.
```

문서를 받으면 숫자를 엑셀과 대조하세요. 문서는 보기 좋게 나와도 **숫자가 틀리는 일이 표보다 흔해요.**

- 문서의 부서별 지출이 실습 결과 엑셀의 부서별 합계와 같나요?
- 예산이 예산표의 값과 같나요? 월 예산과 분기 예산을 섞어 쓰지 않았나요?
- 집행률 하나를 계산기로 직접 계산해 봤나요?
- 엑셀에 없는 숫자(전년 대비, 업계 평균 등)가 들어 있지 않나요? 있다면 AI가 지어낸 거예요.

문서의 숫자는 근거 파일보다 정확할 수 없어요. 「정리 후」 시트에 중복 행이 남아 있으면 집행률도 그만큼 틀려요.

## 6. 넣기 전에 지울 것

데이터에는 개인정보와 거래정보가 섞이기 쉬워요. 이름·연락처·단가 같은 기밀정보 열을 **지운 뒤** 폴더에 넣거나 첨부하세요. (2주차 참고) 열 이름만 바꿔도 충분한 경우가 많아요. 실제 값이 필요 없다면 넣지 마세요.

회사 문서에 보안(DRM)이 걸려 있다면 순서를 지키세요. **기밀정보를 먼저 지우고, 보안은 그다음에 풀어요.** 거꾸로 하면 기밀정보가 담긴 파일이 보호 없이 내 PC에 남아요.

- 숨긴 시트, 숨긴 열, 필터로 가려진 행, 피벗테이블의 원본 시트에 지운 줄 알았던 정보가 잘 남아요. 하나씩 확인하세요.

### 실제로 일할 때도 똑같이 지켜요

이 절차는 실습용 요령이 아니에요. AI는 폴더 안 파일을 내가 하나하나 보지 않은 채로 읽어요. 그래서 **폴더에 무엇을 두느냐가 곧 무엇을 넘기느냐**예요.

| 지킬 것 | 왜 |
|---|---|
| AI 작업용 폴더를 따로 만든다 | 업무 폴더를 그대로 가리키면 그 안의 모든 파일이 대상이 돼요 |
| 그 폴더에는 개인정보·대외비를 지운 사본만 넣는다 | 원본을 두면 지울 기회가 없어요 |
| 넣기 전에 숨긴 시트·열·행을 확인한다 | 화면에 안 보여도 파일에는 그대로 있어요 |
| 파일을 추가할 때마다 같은 확인을 반복한다 | 한 번 정리한 폴더도 새 파일이 들어오면 다시 위험해져요 |

회사 일에 쓴다면 회사의 정보보호 규칙이 이 방식에도 똑같이 적용돼요.

실습 파일 대신 내 업무 데이터로 해도 돼요. 그럴 땐 6번대로 기밀정보를 먼저 지우고, 지시문의 시트 이름·머리글 행·데이터 범위를 내 파일에 맞게 바꿔서 보내세요.

### 1단계. 연결 확인

```text
이 폴더에 있는 파일 목록을 보여줘. 3주차-실습데이터.xlsx 와 3주차-부서별예산표.xlsx 가 둘 다 있는지 확인하고, 파일마다 어떤 시트가 있고 무슨 내용인지 한 줄씩 정리해줘. 아직 아무것도 고치거나 만들지 마.
```

### 2단계. 저장 위치 정하기 (Claude)

```text
정리한 결과는 원본을 고치지 말고 같은 폴더 안 output 폴더에 새 파일로 저장해줘.
```

원본 파일은 끝까지 그대로 둬요. 검산할 때 대조에 써요.

### 3단계. 지출내역 정리

「지출내역」 시트의 데이터 36행을 정리해 실습 결과 엑셀 파일을 만들어요. 4~6단계 내용도 이 파일에 시트로 더해 가요.

- **표가 1행부터 시작하지 않아요.** 1행은 표 제목, 2행은 안내 문구, 열 이름(일자·부서·항목·금액·비고·담당)은 3행, 실제 데이터는 4행부터 39행까지 36행이에요. AI가 이걸 모르면 1행 제목을 열 이름으로 읽거나 제목 줄까지 데이터로 세요.
- **일부러 어긋난 값이 섞여 있어요.** 실제 자료에서 흔히 보는 것들이에요. 무엇이 어긋났는지 찾는 것부터가 실습이에요.

**먼저 찾게 해요.** 바로 고치게 하지 말고 목록부터 받으세요.

```text
「지출내역」 시트는 1~2행이 제목과 안내이고, 열 이름은 3행, 데이터는 4행부터 39행까지야.
이 표에서 형식이 어긋나거나 이상한 값을 먼저 찾아서 행 번호와 함께 목록으로 보여줘. 아직 고치지는 마.
```

**목록이 맞는지 확인한 뒤 정리를 맡겨요.** 빠진 게 있으면 더해서 말하세요.

```text
확인했어. 이 기준으로 정리해서 output 폴더에 3주차-실습결과.xlsx 로 저장해줘.
- 「정리 전」 시트에는 원본 표를 그대로 복사해줘.
- 「정리 후」 시트에는 정리한 표를 넣고, 표 아래에 어떤 행을 어떻게 고쳤는지 적어줘.
```

받은 파일을 열어 직접 확인해요. 「정리 후」의 행 수와 금액 합계가 맞는지 봐요. (본문 5번)

**정리된 표로 요약도 받아 봐요.**

```text
3주차-실습결과.xlsx 의 「정리 후」 시트는 1분기(1~3월) 부서별 지출 내역이야.
부서별 합계와 전월 대비 증감을 표로 정리하고, 증가폭이 큰 3개 부서만 따로 짚어줘.
결과는 3주차-실습결과.xlsx 에 「부서별 요약」 시트로 넣어줘.
```

원본 대신 「정리 후」 시트를 읽게 한 게 포인트예요. 원본에는 글자로 된 금액, 띄어쓰기가 다른 부서 이름, 중복 행이 섞여 있어서 요약 숫자가 틀리게 나와요.

### 4단계. 수식 1개와 검산

AI가 준 수식은 범위를 잘못 잡아도 오류 없이 그럴듯한 숫자를 내요. 그래서 **답을 미리 아는 값으로 맞춰 보는 것**이 가장 확실한 확인이에요.

**① 수식 받기**

```text
3주차-실습결과.xlsx 의 「정리 후」 시트로 부서별 1월 금액 합계를 구하는 수식을 만들어줘. 엑셀 2019에서 동작해야 해.
「수식과 검산」 시트를 새로 만들어 그 수식을 넣어줘.
```

**② 검산하기.** 아래 중 하나 이상 해 보세요.

- 한 부서의 한 달을 골라 원본 금액을 계산기로 더하고 수식 결과와 비교해요. (예: 영업1팀 1월)
- 부서별 1월 합계를 모두 더한 값이 1월 전체 합계와 같은지 봐요.
- 엑셀에서 해당 금액 칸을 드래그해, 화면 아래 상태 표시줄의 「합계」와 비교해요.

```text
「수식과 검산」 시트에 검산 결과를 적어줘.
확인 방법: … / 예상값: ○○○ / 수식 결과: ○○○ / 같았는지, 달랐다면 이유: …
```

결과가 다르게 나오는 흔한 이유는 3단계 정리가 덜 된 거예요. 글자로 남은 금액은 더해지지 않고, 표기가 다른 부서 이름은 조건에서 빠져요. **틀린 결과를 찾아 원인을 적은 건 잘한 검산이에요.**

### 5단계. 예산과 비교하기

실습 결과를 다른 파일(부서별 예산표)과 엮어 비교해요. 실제로 보고서 숫자는 대개 파일 두세 개를 맞춰 봐야 나와요.

```text
3주차-실습결과.xlsx 의 「정리 후」 시트와 3주차-부서별예산표.xlsx 의 「부서별예산」 시트를 읽어줘.
부서별로 1분기 예산, 실제 지출, 집행률(지출 ÷ 예산)을 표로 만들어 3주차-실습결과.xlsx 에 「예산 대비」 시트로 넣어줘.
예산을 넘긴 부서는 따로 짚어 주고, 숫자는 두 파일에 있는 값만 써줘. 표 아래에 각 숫자를 어느 파일 어느 시트에서 가져왔는지 적어줘.
```

집행률이 이상하게 높게 나오면 「정리 후」 시트에 중복 행이 남아 있지 않은지 먼저 보세요.

<summary><b>검산용 정답 보기</b> (3~5단계를 다 한 뒤에 열어 보세요)</summary>
<ul style="margin:8px 0 0">
<li>원본 데이터 36행 중 <b>완전히 같은 중복 행이 1개</b> 있어요. 중복을 지우면 35행이에요.</li>

<li>1분기 예산을 넘긴 부서: <b>개발팀</b> (지출 584,000원 ÷ 예산 530,000원 ≈ 110.2%)</li>
<li>월 예산을 넘긴 달: <b>마케팅팀 2월</b>, <b>개발팀 2월·3월</b></li>
</ul>

### 6단계. 내 일 자동화 아이디어 5개

여기부터는 실습 데이터와 상관없어요. **내 실제 일을 돌아보는 단계**예요. 결과만 같은 엑셀 파일에 시트로 모아 둬요.

내가 반복하는 일을 알려 주고 자동화 아이디어를 받아요. 표 작업이 아니어도 돼요. 메일·보고서·회의·문서 정리처럼 매주·매달 비슷하게 되풀이하는 일이면 뭐든 돼요.

```text
나는 ○○팀에서 매달 ○○ 표를 만들어. 이런 반복 작업을 AI로 줄일 수 있는 아이디어 5개를 줘.
3주차-실습결과.xlsx 에 「자동화 아이디어」 시트를 만들어 5개를 적어줘.
```

표가 아닌 일이라면 첫 줄을 이렇게 바꿔 보세요. 둘째 줄은 그대로 붙여요.

- `나는 매주 월요일, 지난주 거래처 미팅 메모를 모아 팀장님께 주간 보고 메일을 써.`
- `나는 부서마다 메일로 따로 오는 비품 신청을 모아 구매 요청서에 옮겨 적어.`
- `나는 매주 팀 회의가 끝나면 회의록을 정리하고, 할 일을 담당자별로 나눠 메일로 돌려.`
- `나는 고객 문의 메일에 비슷한 내용의 답장을 매번 새로 써.`
- `나는 분기마다 지난 보고서를 열어 날짜와 숫자만 바꿔 새 보고서를 만들어.`

일을 설명할 때 회사 이름·고객 이름·금액은 적지 마세요. 「거래처A」, 「○○ 제품」처럼 바꿔 적어도 충분해요.

**5개를 받았다고 끝내지 말고 이어서 물어보세요.** 처음 받은 아이디어는 대개 일반적이에요. 내 사정을 더 알려 주고 되물을수록 실제로 써먹을 수 있는 쪽으로 좁혀져요.

- `내 일을 더 정확히 알려면 무엇을 더 알아야 해? 필요한 걸 나한테 질문해줘.`
- `3번 아이디어를 내일 바로 해 보려면 첫 단계로 뭘 하면 돼?`
- `이 중에 지금 내가 쓰는 도구만으로 할 수 있는 것과, 다른 프로그램이나 권한이 더 필요한 것을 나눠줘.`
- `2번 아이디어를 하면 사람이 꼭 직접 확인해야 하는 부분은 어디야?`
- `5개 중에 효과는 크고 손은 덜 가는 것부터 순서를 매겨줘.`

마지막으로, 아이디어마다 **내가 판단한 실현 가능성(높음/보통/낮음)과 이유**를 불러 주고 시트에 한 줄씩 붙이게 하세요. 근거는 이 세 가지로 적으면 돼요.

- 얼마나 자주 하는 일인가
- 들어오는 자료의 형식이 매번 비슷한가
- 결과가 맞는지 확인하기 쉬운가

처음 받은 5개와 대화하며 바뀐 5개가 다르다면, 그게 잘한 거예요.
